# Project Dependencies

This project relies on the following Python libraries:

- streamlit==1.26.0
- pandas==2.0.3
- numpy==1.24.3
- matplotlib==3.7.2
- plotly==5.15.0
- seaborn==0.12.2

## Installation

On Replit, these dependencies are automatically managed. For local development, you can install them using pip:

```bash
pip install streamlit pandas numpy matplotlib plotly seaborn
```

Or if you prefer specific versions:

```bash
pip install streamlit==1.26.0 pandas==2.0.3 numpy==1.24.3 matplotlib==3.7.2 plotly==5.15.0 seaborn==0.12.2
```
